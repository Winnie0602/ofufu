# Task 003: Footer 手機版精簡

## 狀態

`Completed`

## 目標

縮短全站手機版 Footer 高度，保留品牌資訊、社群連結與必要的網站資訊導覽。

## Scope

- 手機版品牌資訊與社群連結維持置中。
- 手機與平板版隱藏 Footer 的「學習內容」導覽，教材入口保留在 Header 等主要導覽區域。
- 平板版以品牌資訊、「關於我們」及「相關資源」三欄排列，避免第三個區塊掉到下一列。
- 桌面版保留「學習內容」，沿用原本的四欄 Footer 排版。
- 平板與桌面版的主要內容使用較窄的置中容器，避免視覺重心偏向左側。
- 「關於我們」與「相關資源」沿用原本的垂直連結排版。
- 其餘間距、對齊與視覺樣式回復原始 Footer 設定。
- 不新增 Accordion、Vue state 或其他 JavaScript 互動。

## Out of Scope

- 修改保留下來的 Footer 導覽內容與目的地。
- 新增或更換社群連結。
- Header 與其他全站元件改版。

## Acceptance Criteria

- [x] 手機與平板版不顯示「學習內容」導覽。
- [x] 768px 平板版的三個可見區塊保持同列排列。
- [x] 平板與桌面版的主要內容在 Footer 中水平置中。
- [x] 桌面版顯示「學習內容」，並維持四欄排版。
- [x] 「關於我們」與「相關資源」維持原本的垂直連結排版。
- [x] 手機版 Footer 高度較目前明顯縮短。
- [x] 375px 與 390px 寬度不產生水平捲動。
- [x] 所有導覽與社群操作仍可清楚辨識及點擊。
- [x] 平板與桌面版主要排版沒有退步。
- [x] Footer 通過 ESLint，專案通過 production build。
